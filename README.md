# Site para Nutricionista (Demo)

Landing page responsiva para um consultório de nutrição, com agendamento pelo WhatsApp, depoimentos, horários e mapa.

> ⚠️ **Versão de demonstração.** Este projeto foi feito como proposta para um cliente. Nesta versão de portfólio, o nome da profissional, o endereço, o telefone, as fotos e os depoimentos foram trocados por **dados fictícios**.

## Funcionalidades

- Botões de agendamento que abrem o WhatsApp com uma mensagem pronta
- Seções de atendimento, depoimentos, horários e localização com mapa
- Layout responsivo (celular e computador)
- SEO: título, descrição, Open Graph e dados estruturados (`schema.org`)

## Tecnologias usadas

- React + TypeScript
- TanStack Start / TanStack Router
- Tailwind CSS
- Vite

## Como rodar o projeto

1. Instale o [Node.js](https://nodejs.org/) (versão 20 ou mais nova).
2. Baixe o repositório:
   ```bash
   git clone https://github.com/Eliseu2013/site-nutricionista-demo.git
   cd site-nutricionista-demo
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Rode em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra no navegador o endereço que aparecer no terminal.
